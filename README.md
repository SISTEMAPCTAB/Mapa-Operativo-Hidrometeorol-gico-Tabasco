# Mapa Operativo Hidrometeorológico de Tabasco

Piloto independiente para visualizar lluvia observada, niveles hidrométricos y una alerta operativa compuesta.

## Principio de seguridad

Este repositorio **no escribe ni modifica** el proyecto `Agente-Hidrometeorologico-Cloud`. Consume sus archivos públicos en modo lectura desde GitHub Pages.

## Alerta operativa piloto

Combina:

- referencias hidrométricas publicadas por CONAGUA/OCFS cuando pueden estructurarse;
- tendencia y variación de niveles;
- lluvia observada CONAGUA y WeatherLink;
- intensificación preventiva cuando coinciden ascenso y lluvia intensa.

La alerta operativa no sustituye el semáforo oficial de CONAGUA/OCFS.

## Estado

Primera versión piloto. Las ubicaciones actuales son referencias geográficas y deben reemplazarse progresivamente por coordenadas oficiales de estación.
